# Demo data

Every person in this folder is invented: names, profile URLs, titles and the
`@example.com` email addresses were generated by
`scripts/generate-mock-connections.mjs` and nothing here describes a real
person. "Lumenkeep", the demo user's own small company, is invented. The other companies are real Finnish and international companies, used only
so that matching against the PRH trade register can be tested on realistic,
messy company names; being listed here says nothing about any company's
relationship with anyone, and no invented person is given a CEO, managing
director, owner or founder title at a real company.

| File | What it is |
| --- | --- |
| Connections.csv | Mock LinkedIn export for "You", 1,500 rows, same format as LinkedIn's Connections.csv |
| Connections-cofounder.csv | Mock export for "Co-founder", 860 rows, 270 people shared with Connections.csv by profile URL |
| Connections-board.csv | Mock export for "Board member", 300 rows, 60 people shared with the other two |
| Connections-small.csv, story/ | The original 57-row story demo, kept for the old tests |
| profile.json | The demo's invented profile (goal, roles, industries, ask, tone, signature), used while only the demo networks are loaded and you have not set your own. Its `excluded` list holds large groups the demo user marks as not a target (KONE, Valmet, Wärtsilä, Kemira, …): a choice, not a fact about the companies |
| statuses.json | Two of the invented demo team's own records, loaded with the demo: a message sent on 14 Oct with no reply (a follow-up is due) and a meeting on 20 Oct at a company where the team knows others |

Regenerate with `node scripts/generate-mock-connections.mjs` (seeded, same
output every time; `--check-prh` checks the target companies against PRH).
